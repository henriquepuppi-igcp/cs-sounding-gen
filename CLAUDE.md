# igc-sounding-teaser

Repositório usado pela rotina na nuvem que gera os sounding teasers da igc Capital Solutions.

- A skill está em `.claude/skills/cs-sounding-teaser-prospects/`.
- Rode sempre em modo lote, seguindo `references/lote.md` da skill.
- Use `python3` nos comandos.
- Todo o resultado vai para o Box. **Não faça commit, branch nem pull request neste repositório.**
- Arquivos de trabalho ficam em `/tmp/teaser/`.
